# React Notes App

A simple Notes application built using React.  
Users can add, delete, and persist notes using browser localStorage.

## Features
- Add and delete notes
- Data persistence using localStorage
- Clean and responsive UI
- Built with React Hooks

## Technologies Used
- React
- JavaScript
- HTML & CSS

## How to Run
1. Clone the repository
2. Run `npm install`
3. Run `npm start`
